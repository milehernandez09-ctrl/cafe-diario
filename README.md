# ☕ Diario de Café

Tu bitácora personal de cafés de especialidad con puntuación SCA.

## Características
- Registro rápido y modo Coffee Expert
- Puntuación SCA (Specialty Coffee Association)
- Múltiples preparaciones por café (V60, AeroPress, Chemex...)
- Análisis con IA de la etiqueta del paquete
- Descriptores sensoriales (cuerpo, acidez, notas aromáticas)
- Tres idiomas: ES / EN / DE
- Exportar a CSV / Google Sheets
- Funciona offline (PWA)
- Almacenamiento local IndexedDB

## Instalar como app
Abre la URL en Chrome (Android) o Safari (iPhone) y toca "Añadir a pantalla de inicio".

## Tecnología
HTML + CSS + JavaScript puro · IndexedDB · Claude AI API · Service Worker
